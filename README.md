# Tracker

Приложение для отслеживания привычек. Учебный проект Яндекс Практикума, четвёртый модуль курса iOS-разработчик.

## Стек

- Swift, UIKit, вёрстка кодом (без сторибордов, кроме `LaunchScreen`)
- `UICollectionView` с `UICollectionViewFlowLayout` — список трекеров
- Минимальная версия iOS — 17.0, только iPhone, только портретная ориентация
- Внешних зависимостей нет

## Экраны

| Экран | Содержимое |
|---|---|
| Онбординг | две страницы, `UIPageViewController` + `UIPageControl` |
| Трекеры | заголовок, кнопка `+`, `UIDatePicker`, коллекция карточек по категориям, заглушка пустого списка |
| Новая привычка | название трекера, переходы к категории и расписанию, кнопки «Отменить» и «Создать» |
| Расписание | дни недели с переключателями |
| Статистика | пустая вкладка |

## Ветки

Работа по спринтам ведётся в отдельных ветках (`sprint_14`, `sprint_15`, …), каждая уходит в `main` через pull request.
